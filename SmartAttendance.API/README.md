## الحالة

الـAPI الحقيقي للموبايل والويب موجود بـ**`SmartAttendance.Web/Controllers/Api`**
مع طبقة مصادقة توكن Bearer (`ApiTokenAuthHandler`) والصلاحيات والوصول للبيانات.

هذا المشروع شبه فارغ (قالب مشروع) ويبقى بالحل ريثما يُتحقق من انعدام التبعيات.

فوضى تنظيمية.
