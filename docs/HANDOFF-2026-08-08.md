## ٣) دروس النشر (ثلاث علل أُصلحت بالسكربت — لا تُنسَ)

1. `robocopy /MIR` كان يمسح أصول الخادم: `certs\lan.pfx` (فلا يقلع التطبيق) و
   `run-hidden.vbs` (فتفشل المهمة). صار `/XD certs App_Data uploads logs keys`
   و`/XF appsettings*.json run-*.vbs run-*.bat *.pfx` + حارس بعد النسخ.
2. الإيقاف كان يبحث عن `dotnet.exe` والموقع يعمل بـapphost ⟹ تعليق robocopy.
3. حلقة `run-server.bat` بـ`cmd` من System32 تُقيم الموقع وسط النسخ ⟹
   `Stop-SiteProcesses` تقتلها بسطر أوامرها.
4. السكربت كان بلا BOM فلا يقرؤه Windows PowerShell 5.1 (لا pwsh بالجهاز).
5. `sqlcmd` يحتاج `-C`، و`WITH COMPRESSION` غير مدعوم على SQL Express.
