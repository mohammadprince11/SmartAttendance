## 3) 🔴 مصيدتان تسبقان أي تشغيل

### أ) `dotnet run` يكتب على قاعدة الإنتاج

`SqlSchemaMigrator.ApplyAsync` يعمل عند الإقلاع **خارج أي شرط بيئة**
(`Program.cs:444-448`). ومع قاعدةٍ واحدة مشتركة، فـ«شغّله محلياً لأشوف» يطبّق
الهجرات على بيانات حقيقية تماماً كالنشر.

الهجرات الستّ المعلّقة، وأخطرها الأخيرتان:

| الهجرة | الأثر |
|---|---|
| `20260807-01` | فهرس على `AttendanceRecords.AttendanceDate` (بناء على ~63 ألف صفّ) |
| `-02` · `-03` | أعمدة جديدة (نِسَب الوقت الإضافي · نافذة الدلالة والاقتطاع) |
| `-04` | عمود `PayrollRuns.CompanyId` |
| **`-05`** | **تعبئة رجعيّة تكتب على بيانات مسير قائمة** |
| **`-06`** | **جدول `DataProtectionKeys` ⟹ كل الجلسات تُطرد مرّة واحدة** |

**خذ نسخة قاعدة قبل أول إقلاع.** الرجوع بالكود لا يُبطلها.

```powershell
sqlcmd -S . -E -Q "BACKUP DATABASE [<الاسم>] TO DISK='C:\Backups\Zynora-pre.bak' WITH INIT, COMPRESSION, CHECKSUM"
```

### ب) الموقع قد يرفض الإقلاع بعد النشر

`CookieSecurityPolicy` يرمي إن كانت البيئة `Production` بلا إثبات TLS.
والمصيدة أن `launchSettings.json` (الذي يضبط `Development`) **ملف تطوير لا يُنسخ
لمخرَج `publish`** — فالنشر المُصدَّر بلا متغيّر بيئة يُقلع افتراضاً على
`Production`. ولا مفتاح من الثلاثة مُودَع بالمستودع.

افحص قبل النشر (لا يكتب شيئاً):

```powershell
.\scripts\deploy\Publish-Zynora.ps1 -CheckOnly
```

وللنشر الداخليّ على HTTP، المفتاح الصحيح بـ`C:\ZynoraPortal\appsettings.json`:

```json
{ "Security": { "AllowInsecureCookies": true } }
```

**لا تضبط `ForceHttps`** (يجبر HTTPS بلا شهادة فينكسر الدخول) **ولا
`ReverseProxy:Enabled`** (يجعل التطبيق يثق بترويسات `X-Forwarded` بلا وسيط يضبطها).

## 4) ماذا أُنجز بهذه الجلسة

### تبويبة الحضور ← بنية كيان الثمانية
`_Layout.cshtml` — أربع مجموعات من تجميعنا صارت ثمانياً بأسماء كيان وترتيبها الحيّ
(`kayan-attendance-deep-2026-08-07.md` §0). المجموعات ذات الشاشة الواحدة عند كيان
تُعرض روابطَ مباشرةً. شاشاتنا الستّ التي لا مقابل لها لم تُحذف — أُسندت لمجموعتها
الوظيفية. كل `CanRoute`/`CanPage`/`IsUnder` محفوظة.

أُصلح بالطريق:
- **`/Holidays` كان مساراً حيّاً بالكتالوج بلا أي رابط بالقائمة** — لا يُوصَل إليه
  إلا بكتابة العنوان. صار تحت «إعدادات تسجيل الحضور».
- **`attendanceOpen` كان يفحص سبعة مسارات فقط**، فشاشات موجات الحضور تُفتح
  صفحتُها والمجموعة مطويّة. صار يغطّي المودل كله.
- **عنوان الدرج**: وُضعت «رسومات بيانية» بخانة العنوان ثم تُوبعت — `.ky-drawer-title`
  يأخذ `cursor:default` و`zynora-kayan-nav.js:166` يستثنيه من إغلاق الدرج، فالخانة
  **عنوانٌ لا رابط**. صارت `<div role="heading">` كما بمجموعة «أشخاص».

### سكربت النشر — `scripts/deploy/Publish-Zynora.ps1`
يُنفّذ الإجراء الآمن كاملاً ويفشل مبكراً: لا يبدأ بلا `-Approve` وكتابة `DEPLOY`؛
لا يلمس شيئاً قبل نجاح نسختَي الملفات **والقاعدة**؛ يفحص الإقلاع قبل النشر (§3.ب)؛

نجت بعد `/MIR`؛ يقيس `/health/ready` ويرجع الملفات تلقائياً إن لم يستجب.
و`-CheckOnly` يشغّل الفحص وحده.
