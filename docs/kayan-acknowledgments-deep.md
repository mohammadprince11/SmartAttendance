## 1) ما هو «الإقرار» أصلاً؟

مستند تُلزِم الشركة الموظف بقراءته والموافقة عليه صراحةً — سياسة أخلاقيات العمل،
سياسة الخصوصية، لائحة الجزاءات، اتفاقية عدم إفشاء… **والقيمة كلها في الإثبات**:
أن فلاناً استلم ورأى ووافق بتاريخ محدَّد.

المثال الحيّ بالديمو: **«سياسة أخلاقيات العمل»**.

---

## 2) شاشة القالب

**أعمدة القائمة:** `اسم القالب` · `الوصف` · **`أرسل تلقائياً إلى الموظفين الجدد`** · `نشط`

**داخل القالب** (فتحته):

```
إعداد نموذج الإقرار
├── اسم القالب                    (سياسة أخلاقيات العمل)
├── أرسل تلقائياً إلى الموظفين الجدد   (نعم/لا — الحيّ: لا)
└── العناصر المنسوخة → أنشئ نسخة
```

ونصّ كيان أعلى الشاشة:
> «لتغيير نموذج الإقرار **على مستوى وحدة العمل، أنشئ نسخة**.»

⟹ نفس نمط «سياسة أمّ + نُسَخ مشروطة» المتكرّر بكل صفحات الإعدادات: إقرار مختلف
لكل وحدة عمل (لأن اللوائح تختلف بين الأردن والسعودية مثلاً).

> ⚠️ **تصحيح:** كتبتُ أولاً أنه «لا يوجد محرّر محتوى بالشاشة، والأرجح أن النصّ
> يأتي من منشئ الوثائق». **هذا خطأ** — سببه أنّي فتحتُ شاشة *عرض* القالب القائم
> لا شاشة *الإنشاء*. الصحيح مفصَّل بالقسم التالي.

### نموذج الإنشاء الكامل (`إنشاء قالب جديد`)

الزرّ مخفيّ خلف مفتاح ☰ بشريط العنوان — نفس نمط قوالب المهام. والنموذج يحوي:

| الحقل | النوع | ملاحظة |
|---|---|---|
| `lstName[i].Description` | نص ×2 | **اسم القالب** بالعربية + لغة أخرى |
| `Description` | textarea | الوصف الإداري |
| `lstTitle[i].Description` | نص ×2 | **عنوان الإقرار** بلغتين (ما يراه الموظف) |
| **`lstBody[i].Description`** | **محرّر نصّ غنيّ ×2** | **نصّ الإقرار كاملاً بلغتين** |
| `Attachment` | ملف | مرفق (نسخة PDF من اللائحة مثلاً) |
| `SendAutomaticallyToNewHired` | شيك | الإرسال التلقائي للموظفين الجدد |
| `Active` | شيك | |
| `btnSaveAcknowledges` | حفظ | |

**محرّر النصّ ليس بسيطاً** — شريط أدوات كامل: عريض/مائل/تسطير/يتوسطه خط ·
مرتفع/منخفض · محاذاة (يسار/وسط/يمين/ضبط) · قوائم مرقّمة بأنماط (Lower Alpha ·
Lower Greek · Lower/Upper Roman) وقوائم نقطية (دائرة/قرص/مربع) · إزاحة · **إدراج
صورة وجدول وخطّ أفقي ورابط** · ملء الشاشة · **عرض الكود (HTML)** · تحديد الكل ·
لون النصّ والخلفية · مسح التنسيق · **تباعد الحروف** (0.25 → 3) · أحجام خطّ 8→96 ·
وقائمة خطوط تشمل **`DIN Next LT Arabic`** و**`Unilever Shilling`**.

> الخطّان الأخيران لافتان: خطوط **مخصّصة للعميل** داخل المحرّر — أي أن الوثائق
> تُطبع بهوية الشركة البصرية، لا بخطّ افتراضي.

⟹ **الإقرار وثيقة مكتملة بذاته** (عنوان + نصّ منسَّق بلغتين + مرفق)، ولا يعتمد
على منشئ الوثائق.

### المفتاح الأهم: «أرسل تلقائياً إلى الموظفين الجدد»

شيك واحد يحوّل الإقرار من إجراء يدوي إلى **جزء من مسار التعيين**: كل موظف جديد
يستلمه تلقائياً. ويلتقي هذا مع «قوالب مهام الموظفين» و«قوالب إنهاء الخدمات» —
كيان يبني **الأتمتة حول الأحداث** (تعيين · إنهاء · تجديد عقد).

## 3) شاشة المتابعة — هنا القيمة الحقيقية

**الأعمدة الخمسة:**

| العمود | المعنى |
|---|---|
| `اسم الموظف` | المستلِم |
| `اسم القالب` | أي إقرار |
| **`تاريخ الإرسال`** | ختم زمني (صفوف حيّة من 2024 إلى 2026) |
| **`تمت مشاهدتها من قبل الموظف`** | نعم / لا |
| **`موافقة الموظف`** | نعم / لا / فارغ |

⟹ **فصل «المشاهدة» عن «الموافقة» مقصود ومهمّ قانونياً**: صفٌّ حيّ بالديمو يقول
`مشاهدة = لا` و`الموافقة = فارغة` — أي موظف أُرسل له الإقرار **ولم يفتحه**. وهذا
بالضبط ما تحتاجه الشركة لتقول «أُبلِغ ولم يستجب».

وصفوف الموظف نفسه تتكرّر بتواريخ مختلفة ⟹ **الإقرار يُعاد إرساله دورياً** (تحديث
سياسة، أو إقرار سنوي)، وكل إرسال سجلّ مستقل.

## 4) بماذا ترتبط

```
قالب الإقرار
├── يُرسل تلقائياً عند التعيين      → مسار الموظف الجديد
├── نُسَخ لكل وحدة عمل             → تعريفات الشركة
├── يظهر للموظف بـ                 → بوابة الخدمة الذاتية
├── يُشعَر به عبر                   → مركز الإشعارات
└── أثره يُتابَع بـ                 → متابعة الإقرارات (مشاهدة + موافقة)
```

ومن مركز إشعارات كيان الذي درسناه، أحداث مثل **«مشاركة الوثائق»** و**«الترحيب
بموظف جديد»** تخدم هذه الدورة نفسها.

## 6) لماذا تستحق البناء عندنا (رأيي)

هذه من **أرخص الفجوات تنفيذاً وأعلاها قيمة قانونية**:

- البنية بسيطة: جدول قوالب + جدول إرسالات (`EmployeeId`, `TemplateId`, `SentAt`,
  `ViewedAt`, `AcceptedAt`).
- القنوات جاهزة عندنا: بوابة الموظف تعمل، ومركز الإشعارات يعمل، والبريد يعمل.
- ولا تحتاج منشئ وثائق: يكفي نصّ غنيّ أو ملف PDF مرفق بالمرحلة الأولى.

وأثرها العملي مباشر: أي نزاع عمّالي حول «هل أُبلغ الموظف باللائحة؟» يُحسم بصفّ
واحد بجدول. اليوم لا نملك هذا الصفّ.
