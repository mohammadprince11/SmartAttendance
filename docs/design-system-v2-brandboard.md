# ZYNORA Design System v2 — المواصفة المستخرَجة من لوحة الهوية

> **المصدر**: لوحتا الهوية (فاتحة + داكنة) التي اعتمدها محمد 2026-08-02.
> هذا الملف يترجم اللوحتين إلى مواصفةٍ قابلة للتنفيذ — لا اجتهاد، كل قيمة
> مقروءة من اللوحة نفسها.

## ٢· الخط

**Poppins** — «Modern · Clean · Professional» كما نصّت اللوحة.

⚠️ **Poppins لا يحوي محارف عربية.** والواجهة عربية RTL بالكامل، فالاقتران إلزامي:
- **Poppins** للأرقام واللاتيني (الأرقام هي بطل اللوحة: 248 · 196 · AED 1.24M).
- خطّ عربي مقترن للنص العربي.

⚠️ **مشكلة قائمة**: `Tajawal` مُعلَن بالـCSS لكنه **غير محمَّل** — لا `@font-face`
ولا رابط Google Fonts بالقوقعة. فهو يظهر فقط على جهازٍ مثبَّت عليه، وإلا سقط
النظام صامتاً إلى `Segoe UI`. أي خطٍّ نعتمده يجب أن **يُشحن مع التطبيق**
(ملفات محليّة بـ`wwwroot/fonts` + `@font-face`) — لا رابط خارجي، لأن الإنتاج
يعمل خلف نفق وقد يُقيَّد الوصول الخارجي.

## ٣· بنية لوحة البيانات (النموذج المرجعي)

```
┌─ قائمة جانبية ─┬─ شريط علوي: بحث عام + جرس بشارة ──────────────┐
│ الشعار         │  ترويسة: «أهلاً بعودتك، عمر 👋» + سطر وصف      │
│                ├────────────────────────────────────────────────┤
│ ▸ لوحة البيانات│  ٤ بطاقات KPI                                  │
│   الموظفون     │  [عنوان رمادي صغير · رقم ضخم · دلتا ملوّنة]     │
│   الحضور       │  [+ أيقونة بمربّع ملوّن ناعم بالزاوية]          │
│   الرواتب      ├────────────────────────────────────────────────┤
│   الإجازات     │  مخطط خطّي (بمنسدلة «هذا الشهر») │ مخطط دائري   │
│   الأداء       │  + نقطة قيمة مميّزة بشارة        │ مجوّف بالرقم  │
│   التقارير     │                                   │ بالوسط+نِسَب │
│   الإعدادات    ├────────────────────────────────────────────────┤
│                │  ٣ بطاقات أقسام: عنوان + «عرض الكل»            │
│ ┌────────────┐ │  وثلاث قيم فرعية ملوّنة (أخضر/ذهبي/أحمر)       │
│ │صورة·اسم·دور│ │                                                │
└─┴────────────┴─┴────────────────────────────────────────────────┘
```

**تفاصيل ملزمة قرأتُها من اللوحة:**
- العنصر النشط بالقائمة: خلفية تيل **صلبة** بزوايا مستديرة ونصّ أبيض.
- بطاقة KPI: العنوان رمادي صغير · الرقم ضخم جداً وثقيل · سطر الدلتا بسهم ولون
  دلالي (`↑ 12 هذا الشهر` · `79% من الإجمالي`) · أيقونة داخل مربّع بلون ناعم.
- بطاقات الأقسام السفلية: رابط «عرض الكل» بالتيل أعلى-اليسار، وثلاث قيم بألوان
  دلالية (معلَّق ذهبي · معتمَد أخضر · مرفوض أحمر).
- بطاقة المستخدم أسفل القائمة: صورة دائرية + اسم + دور + سهم منسدلة.

## ٧· ترتيب التنفيذ المقترح

1. **التوكنز والخطوط** — اللوحتان + شحن الخطوط + إدخال الذهبي. يمسّ كل الصفحات
   بكوميت واحد ومخاطرة منخفضة.
2. **لوحة البيانات `/Index`** — النموذج المرجعي؛ تُبنى طبق اللوحة وتُعرض على محمد.
3. **الأيقونات** — طقم ستروك موحّد بالشرطة الذهبية.
4. بقية الصفحات على النمط، بعد اعتماد النموذج.

**ممنوع أثناء التنفيذ** (يبقى من v1): تغيير أي وظيفة أو حقل أو بيانات، ومكتبات
ثقيلة، وأنيميشن فوق 250ms.
