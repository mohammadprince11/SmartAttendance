## أ) ما يملكه النظام اليوم (مؤكّد بالكود والنشر الحي)

**اللبّ مكتمل وقوي:** الأشخاص (ملف 360 + حقول داينمك + استيراد ذكي + استيراد بريد) ·
الحضور (محرك اشتقاق كامل: مناوبات بكل إعداداتها المفعّلة — نافذة التقاط، منتصف ليلي، سماحيات،
مغادرات، قواعد تعارض، تجريد دلالات — روستر/تجاوزات/اعتماد شهري بحارس أيام غير محلّلة) ·
الرواتب (مسير كامل بضريبة العراق التصاعدية + ضمان + نهاية خدمة + قروض/سلف + مركز طلبات مالية +
محرك صيغ + ملف بنك + مخصّصات PayrollProvisions) · الموافقات (قوالب لجان + سريان) ·
الإشعارات (3 قنوات حية: جرسا back-office والبوابة + SMTP مصادَق E2E + Web-Push) ·
البوابة PWA (بصم أونلاين بقاعدة مهلة انصراف، بصمة مفقودة، طلبات داينمك، طلب مالي، **طلب مناوبة**،
تغيير كلمة مرور، درج إعدادات) · White-Label كامل + أدوار وصول + لوحة داينمك + API موبايل ·
323 اختباراً أخضر.

**نقاط تفوّق على المنافسين (من الدراسات):** الدخول الموثوق (فشل الدخول أبرز شكاوى منافسينا) ·
المركز الداينمك (حقول/طلبات/لوحة) · White-Label · التوطين العراقي للرواتب.

## ج) الفجوات الحقيقية المتبقية (فحص كود 2026-07-27 — غير مبنية)

### 🔴 المستوى 1 — أعلى قيمة/جهد معقول، تركب على الموجود
1. **إنفاذ Geofencing للبصم الأونلاين** — عندنا `EmployeeGeoLocations` (المواقع تُسجَّل) لكن
   `OnlinePunchStore` **لا يتحقق من نصف قطر/نطاق** قبل قبول البصمة. الإنفاذ = شرط مسافة بسيط
   وقت البصم + إعداد نطاق للفرع. (فجوة تكامل لا بناء)
2. **قوالب باقات الراتب** (Salary Package Templates) — حزمة أساسي+بدلات+استقطاعات لكل
   درجة/منصب تُطبَّق دفعة. جهد صغير فوق SalaryItems، توفير إدخال كبير.
3. **بصم QR ديناميكي** — رمز متجدد على شاشة الفرع يُمسح من PWA (حل حضور بلا أجهزة للعملاء
   الصغار؛ ميزة ZenHR المميزة الرخيصة). يركب على البصم الأونلاين القائم.
4. **تقارير جدولية بريدية مجدولة** — صار عندنا SMTP حي + كرون يومي: تقرير حضور/مسير دوري
   لبريد الإدارة (يبني حصراً على ما اكتمل هذا الأسبوع — لم يكن ممكناً قبله).

### 🟠 المستوى 2 — قيمة عالية، جهد أكبر
5. **محرك تقارير جدولي موحّد** (أعمدة/تجميع/محور/تصدير ag-Grid-style) — PeopleReports صفحة
   واحدة بسيطة؛ الفجوة محرك يخدم الحضور+الرواتب+الأشخاص معاً (فجوة مشتركة مع كيان).
6. **تفويض/تجاوز بالموافقات** (Delegation/Override) — المحرك متعدد الخطوات موجود، ينقصه
   «فوّض غيابي لفلان» و«تجاوز إداري». لا أثر لهما بالكود.
7. **قوالب الخطابات + توقيع** (عرض عمل/إثبات توظيف بهوية الشركة) — يركب طبيعياً على محرك
   الهوية White-Label. لا أثر بالكود.
8. **ملخّصات AI للحضور** (أنماط تأخر/غياب + تقرير أسبوعي) — عبر Claude API بمبدأ
   «اقتراح لا كتابة» المطبَّق أصلاً بمحرك الاقتراحات.

### 🟡 المستوى 3 — موديولات كاملة (قرار منتج، ليست «فجوات» بل توسعات)
9. **تقييم الأداء** (دورات/كفاءات/OKR) — غائب كلياً؛ أكبر موديول متبقٍ مقابل ZenHR.
10. **التأمين الصحي** (فئات + خصم آلي بالمسير) — غائب.
11. **مراكز التكلفة** — يظهر كحقل بحركات المسير فقط؛ لا إدارة/تقارير لها.
12. **i18n بوابة الموظف** — مؤجّل باتفاق (المرحلة 2 لدرج الإعدادات).

### ⚪ مؤكّد تجاهله (خليجي صرف/منخفض القيمة محلياً — قرار الدراسة السابقة ما زال صحيحاً)
