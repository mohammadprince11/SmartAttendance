# ZYNORA Design System v1 — دليل التطبيق صفحة-صفحة
**اعتُمد 2026-07-28** (المرجع البصري: `docs/prototypes/dashboard-redesign-v1.html` + `employee-profile-redesign-v1.html` — فاتح افتراضي، داكن «هادئ»، أيقونات ستروك، «مهمة أولاً»)

## الملفات
- **`wwwroot/css/zynora-design-system.css`** — التوكنز (`--color-*`, `--fs-*`, `--sp-*`) وكل المكونات بكلاسات `zy-*`. محمَّل بالقوقعتين (`_Layout` + `_EmployeePortalLayout`). إضافي — لا يمس ستايلات الصفحات القديمة.
- الأساسي مُجسَّر لمحرك الهوية: `--color-primary: var(--brand-primary, …)` — الـWhite-Label يظل يعمل.

## القواعد الملزمة عند إعادة تصميم أي صفحة
1. **صفر `<style>` بالصفحة وصفر ألوان مباشرة** — فقط كلاسات `zy-*` + توكنز. الاستثناء الوحيد: عرض/ارتفاع خاص جداً بالصفحة.
2. الهيكل القياسي: `zy-breadcrumb` ← `zy-page-header` (عنوان + وصف + **زر أساسي واحد**) ← `zy-stats` (٤ كحد أقصى) ← `zy-filter-bar` ← المحتوى (`zy-table-wrap` أو `zy-card`s) ← `zy-pagination`.
3. «الأقل ظاهر»: الحقول المتقدمة تُطوى بـ`<details>` أو تبويب ثانٍ.
4. الحالات إلزامية: `zy-empty` (لا صفحة فارغة أبداً) + `zy-skeleton` عند البطء.
5. الحالات بالجداول = `zy-badge--*` مع `zy-badge__dot` (لا اعتماد على اللون وحده).
6. التأكيدات تبقى `data-zyconfirm`، والنجاح/الفشل عبر `zy-toast`.
7. المودال للنماذج القصيرة، `zy-drawer` للتفاصيل الكبيرة (ملف موظف/طلب).
8. RTL بخصائص منطقية فقط (لا left/right) — جاهز للـLTR.

## الأنماط الأربعة (كل صفحة تُصب بواحد)
| النمط | المكونات | أمثلة |
|---|---|---|
| قائمة إدارية | header+stats+filter+table+modal | ~30 صفحة (Transactions مرجعها) |
| تفاصيل سجل | phead+tabs+zy-kv بطاقات قراءة+قلم تعديل | ملف الموظف، تفاصيل طلب |
| شبكة تفاعلية | خاص + توكنز | الروستر، المستعرض |
| إعدادات | zy-card أقسام + نماذج | AttendanceSettings وأخواتها |

## خارطة التطبيق (كل صفحة = كوميت + معاينة محمد)
1. ✅ الأساس (هذا الكوميت)
2. لوحة البيانات `/Index` (النموذج الأول — «مهامك اليوم» + 4 KPI + 7 مراكز بالقائمة)
3. الموظفون (قائمة + ملف 360 بنمط التفاصيل)
4. الإجازات (طلب برصيد ظاهر قبل الحفظ + سلسلة الموافقات)
5. التقارير (فلاتر موحدة + تصدير)
6. استيراد إكسل (ويزارد 7 خطوات: ملف←أعمدة←مطابقة←معاينة←أخطاء←تأكيد←نتيجة)
7. بقية القوائم الإدارية بالجملة (قولبة على النمط 1)
8. توحيد القائمة الجانبية لـ7 مراكز + Topbar (بحث Ctrl+K، تبديل الثيم/اللغة)

**ممنوعات**: مكتبات ثقيلة، أنيميشن فوق 250ms، تغيير أي وظيفة/حقل/بيانات أثناء إعادة التصميم.
